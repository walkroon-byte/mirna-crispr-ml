# Cas12a 新训练数据来源与下载说明

本清单按“是否有逐条序列—活性对应关系”分类。下载后必须保留原始文件、来源页面、论文/补充材料、下载日期和 SHA-256；不要只保留转换后的 CSV。

## A. 优先使用：逐条序列—活性表

### 1. EasyDesign / Cas12a Table S2

- 代码与数据仓库：[scRNA-Compt/EasyDesign](https://github.com/scRNA-Compt/EasyDesign)
- 项目内训练数据：`data/EasyDesign/data/Table S2.xlsx`
- 论文/补充材料：进入仓库 README 的论文链接或论文页面，在 Supplementary Information 下载 Table S2。

项目当前已有该文件，并通过 `scripts/process_public_datasets.py` 处理为 `easydesign_processed.csv`。Table S2 的每行包含 guide、target、错配数和活性测量，适合作为逐条序列训练的起点，但使用前仍需核对：guide 长度（当前主要为 25 nt）、活性列的含义、实验时间点、Cas12a 蛋白和是否为同一批次。

Windows 下载仓库：

```powershell
Set-Location D:\Evelyn\mirna-crispr-ml\data
git clone https://github.com/scRNA-Compt/EasyDesign.git EasyDesign_source
Get-ChildItem .\EasyDesign_source -Recurse -Filter 'Table S2.xlsx'
Get-FileHash (Get-ChildItem .\EasyDesign_source -Recurse -Filter 'Table S2.xlsx').FullName -Algorithm SHA256
```

实际路径若包含空格，用 `Get-ChildItem -Recurse -Filter 'Table S2.xlsx'` 查找；不要根据文件名自行推断标签公式。

## B. 真实 Cas12a 实验原始数据：下载后需重建标签

### 2. Sashital Lab Cas12a nickase / plasmid-library HTS

- 代码和方法：[sashital-lab/Cas12a_nickase](https://github.com/sashital-lab/Cas12a_nickase)
- 数据发布页：[Iowa State Figshare, HTS data of plasmid library subjected to Cas12a cleavage](https://iastate.figshare.com/articles/dataset/High-throughput_sequencing_HTS_data_of_plasmid_library_subjected_to_Cas12a_cleavage/8178938/3)
- 项目中已保存的代码仓库：`data/Cas12a_nickase/`

该实验包含 PS4、EMX1、CCR5 等质粒文库，并测试 FnCas12a、LbCas12a、AsCas12a。仓库方法说明显示原始输入为 FASTQ，公开处理结果主要计算错配计数和各位置碱基频率。它是真实 Cas12a 数据，但不能把位置频率直接配给自行构造的单错配序列；要用于监督训练，必须取得处理后的逐序列 cleavage/readout 表，或从原始 FASTQ、输入文库和处理样本重新计算每个实际序列的标签。

推荐下载方法：

```powershell
Set-Location D:\Evelyn\mirna-crispr-ml\data\public_datasets\raw
git clone https://github.com/sashital-lab/Cas12a_nickase.git sashital_cas12a_nickase
Start-Process 'https://iastate.figshare.com/articles/dataset/High-throughput_sequencing_HTS_data_of_plasmid_library_subjected_to_Cas12a_cleavage/8178938/3'
```

在 Figshare 页面选择 **Download all**，解压到：
`D:\Evelyn\mirna-crispr-ml\data\public_datasets\raw\sashital_data\`

下载后先检查文件名、压缩包内 FASTQ 数量、样本条件和 README，再运行：

```powershell
Get-ChildItem D:\Evelyn\mirna-crispr-ml\data\public_datasets\raw\sashital_data -Recurse -File
Get-FileHash D:\Evelyn\mirna-crispr-ml\data\public_datasets\raw\sashital_data\* -Algorithm SHA256
```

### 3. DeepCpf1 / DeepCpf1 guide-activity data

- 论文页面：[Nature Biotechnology, DOI 10.1038/nbt.4061](https://doi.org/10.1038/nbt.4061)
- 入口：打开论文页的 **Supplementary Information**，下载训练/测试表格；同时保留 DOI 页面作为来源记录。

该数据是 Cas12a/Cpf1 guide activity，适合扩充深度学习的序列—活性样本，但它通常是细胞编辑活性/indel 类终点，不等同于 EasyDesign 的体外切割读数。加入项目时应把 `assay_type`、细胞系、Cas12a ortholog、guide length、PAM、测量终点和批次作为字段，并先做跨 assay 的独立验证；不要直接把数值拼到 `relative_activity` 列。

Windows 下载步骤：

1. 打开 DOI 链接并进入 Supplementary Information。
2. 下载所有表格原文件到 `data/public_datasets/raw/deepcpf1/`。
3. 保存论文 PDF/补充材料文件名、下载日期和 SHA-256。
4. 读取原始表头，确认 activity 的定义和单位后再写转换脚本。

## C. 适合作为外部验证或原始测序来源

### 4. NCBI BioProject PRJNA1074843

- BioProject：[PRJNA1074843](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1074843)
- 处理数据入口：[Code Ocean capsule 9398276](https://codeocean.com/capsule/9398276/tree/v1)

项目已有下载脚本记录了这两个入口。优先从 Code Ocean 获取作者提供的处理表；如果只有 SRA 原始读段，则先用 SRA Run Selector 导出 accession，再用 SRA Toolkit 下载。该来源应先视为外部验证/待整理来源，只有在元数据明确存在“实际序列—实验读数”时才纳入训练。

## 不要下载后直接合并的来源

- [finkelsteinlab/nucleaseq](https://github.com/finkelsteinlab/nucleaseq)：项目处理日志已确认它是 Cas9/NucleaSeq，PAM 和酶体系不适用于 Cas12a 训练。
- Sashital 的位置碱基频率矩阵：是真实验统计，但没有逐条序列活性对应关系时，不能转换成单错配标签。
- 任何只给论文图、位置平均值、随机化文库碱基丰度而没有 sequence/readout 对应表的文件：只能作为机制分析或待重建原始数据，不能直接监督训练。

## 下载后的最低核验清单

对每个新数据库建立一份 provenance 表，至少包含：

`source_url, doi_or_accession, downloaded_at, local_file, sha256, enzyme, ortholog, assay_type, guide_length, pam, target_type, activity_definition, replicate_info, sequence_activity_pair_verified`

只有 `sequence_activity_pair_verified=true` 且实验条件字段完整的记录，才进入训练候选集。不同 assay 的标签应保留原始单位，先在分组留出测试集上比较标准化/多任务建模，不能先把不同实验的数值强行缩放到同一列。
