# v7 深度模型继续优化说明

## 1. 为什么原优化模型指标低

第一版深度优化模型在 spacer 分组测试集上的 Spearman ρ 为 0.5683，而训练集为 0.8993。训练与测试之间存在约 0.33 的明显差距，说明主要问题是过拟合和分组外推困难，不是训练没有收敛。

原模型还有一个输入结构问题：它把 spacer 和 target 依次拼接为 40 个位置，卷积核会在 spacer 的末端和 target 的开头之间跨边界滑动。这个邻接关系没有生物学含义，也不直接表达同一位置的碱基配对。

## 2. 第二版做了什么

第二版 `train_model_v7_public_only_deep_optimized_v2.py` 仍使用同一清理数据、同一随机种子和同一 spacer 分组，因此结果可以直接比较。

### 输入改造

每个位置使用 25 个通道：

- spacer 碱基 one-hot：4 个通道
- target 碱基 one-hot：4 个通道
- spacer-target 配对类型 one-hot：16 个通道
- 是否错配：1 个通道

这样网络在位置维度上直接看到 20 个配对位置，不再把 spacer-target 边界当成真实邻接关系。

### 网络改造

- 输入从 `(40, 4)` 改为 `(20, 25)`
- CNN 使用 96 和 128 个卷积通道
- 使用 Bi-LSTM 的序列输出，再用 GlobalMaxPooling1D 汇总
- 使用 `swish` 激活、LayerNorm 和 SpatialDropout1D
- 保留 20 维手工特征分支和融合层
- Adam 学习率为 `5e-4`，batch size 为 64
- 使用 MSE、ReduceLROnPlateau 和 EarlyStopping

## 3. 第二版结果

| 数据集 | Spearman ρ | R² | RMSE | MAE |
|---|---:|---:|---:|---:|
| train | 0.8432 | 0.6846 | 0.1170 | 0.0891 |
| validation | 0.5820 | 0.2861 | 0.1741 | 0.1350 |
| test | 0.5513 | 0.2222 | 0.1831 | 0.1429 |

第一版深度优化模型测试 Spearman ρ 为 0.5683，因此第二版虽然输入更符合错配结构，但在当前测试划分上的最终泛化结果较差。第二版不应替代第一版。

## 4. 当前选择

当前深度学习最佳版本仍是：

`models/v7_public_only_deep_optimized/v7_public_only_deep_optimized_best.h5`

它的测试结果为 Spearman ρ=`0.5683`、R²=`0.2269`、RMSE=`0.1826`、MAE=`0.1409`。树模型版本在同一分组测试上为 Spearman ρ=`0.5930`，目前总体更好。

## 5. 结果如何解释

原 `v7_public_only` 的 Spearman ρ=`0.6832` 来自逐行随机划分；本次优化使用 spacer 分组，测试集包含训练阶段未出现的 spacer。两种评估回答的问题不同，不能把 `0.5683` 直接描述为原模型下降，也不能把 `0.6832` 描述为未见 spacer 的泛化能力。

后续若继续提高深度模型，最有价值的方向是增加真实实验批次或新 spacer 的逐序列标签，并进行多次 GroupShuffleSplit 或按实验批次留出。继续在同一个固定测试集上反复调参，会逐渐把测试集信息带入模型选择。
