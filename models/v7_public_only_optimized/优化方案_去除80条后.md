# 去除 80 条不可用记录后的模型优化方案

## 已执行的版本

优化模型为 `v7_public_only_optimized`，原 `models/v7_public_only/` 文件未覆盖。

另有同一数据划分下的深度学习优化版本 `models/v7_public_only_deep_optimized/`。该版本沿用原 v7 的 CNN+Bi-LSTM+20 维手工特征融合架构。

- 数据：`combined_v4_training_data_cleaned_exclude_unverified80.csv`，9,894 条
- 排除规则：保留清理脚本生成的公开数据-only 文件，不重新构造 80 条标签
- 特征：与 v7 兼容的 spacer/target 前 20 nt one-hot（160 维）+ 20 个位置错配掩码 + 20 个位置的 16 类错配类型 one-hot（320 维）+ 5 个组成摘要，共 505 维
- 划分：按规范化后的 spacer 分组，训练/验证/测试为 6,871/1,502/1,521 条；对应 947/204/204 个 spacer，组间无交集
- 候选模型：ExtraTrees、RandomForest、HistGradientBoosting；只用验证集选模型，测试集只在最后评估
- 选中模型：`HistGradientBoostingRegressor(max_iter=300, learning_rate=0.06, max_leaf_nodes=15, l2_regularization=1.0)`

## 结果

按 spacer 分组的测试集结果：

| 指标 | 优化模型 |
|---|---:|
| Spearman ρ | 0.5930 |
| Pearson r | 0.5710 |
| R² | 0.3244 |
| RMSE | 0.1707 |
| MAE | 0.1356 |

深度学习优化版本测试结果：Spearman ρ=`0.5683`，R²=`0.2269`，RMSE=`0.1826`，MAE=`0.1409`。因此在当前严格的未见 spacer 测试上，树模型结果更好；深度模型结果不能与原来的逐行随机划分指标直接比较。

原 `v7_public_only` 报告中的 Spearman ρ=0.6832 来自逐行随机划分，不能与本次按 spacer 分组的结果直接比较。当前结果更接近“未见过新 spacer”的泛化评估；外部实验批次仍需独立验证。

## 具体优化建议

1. 后续模型比较固定使用按 spacer、实验批次或来源分组的留出；不要再用逐行随机划分作为唯一性能依据。
2. 保留训练集拟合的预处理和固定测试集，记录随机种子、组数、样本数和数据文件哈希，避免测试集反复调参。
3. 若取得真实逐序列实验记录，优先按实验批次建立独立外部测试集；重新核对参考序列、链方向、位置索引和活性归一化公式。
4. 在数据量允许时重复 5 次分组划分，报告 Spearman、RMSE 的均值和区间；只有当提升在多个划分中稳定，才作为模型改进结论。
5. 暂不使用合成标签、SMOTE 或由随机化文库丰度反推单错配活性；这些方法不能恢复缺失的序列—标签对应关系。
